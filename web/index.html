ⓘ 悬浮看说明

全部评分标准

按分组列出每一条的小图（同样从高到低）　·　点小图 = 切换上方主图

口径：主图与小图都是「同一条评分标准下、各模型分值从高到低」的横向柱状图，柱端数字是分值。 百分比类标准横轴固定 0~100%；数值类标准横轴按本条最大值定标，所以只有同一条标准内的柱长可以直接比。 没填分值的模型不进图（小图脚注会写「几个模型有分」），图旁会提示未评分模型数量。

评分标准

一条标准 = 名称 + 分组 + 单位（百分比 / 数值）+ 说明

模型信息

一个模型 = 名称 + 分组 + 若干「评分维度」（选标准 → 填分值）

导入恢复

选一份备份恢复：当前全部评分标准、模型与分值会被清空并整体替换为备份内容（不可撤销）。 备份目录内滚动保留最近 5 份；不是本工具生成的备份会灰显且不可选中。

统计基准

基准 = 基准名 + 描述信息 + 任务提示词；标记记录时固化「名字与说明」——此后配置改名 / 改说明 / 删除都不影响已标记记录

统计映射配置

映射只影响展示层汇总命名，不改变底层扫描与统计数据

套餐设置

为映射提供商维护套餐与模型费用，作为后续配额统计 / 费用估算的基础数据

费用模板

可复用的价格配置，与套餐 / 映射完全独立；在套餐设置的模型费用行「导入」即可复制其价格

从模板导入价格

仅导入价格配置，不改变当前模型名；导入后可继续调整，不保存即放弃

设置 / 改组

组名留空 = 默认组，最长 50 字符；改组不改变列表排序位置

发现统计差异待确认

重建对账发现以下「新扫描值大于既有沉淀」的条目，历史统计尚未改动。勾选后点「更新」按新值精确入账，或点「丢弃」永不再提示该条；先不处理可点「取消」，下次刷新会再次提示。

额度估计

用「官方已用额度变化量 ÷ 同期 token 消耗」反推套餐总额度对应的 token 总量

统计结果快照记录

快照式：写入后与套餐 / 价格 / 映射配置解耦，配置变化不影响已写入记录

基准比较

全库同名基准记录按「套餐 + 模型」分组求均值——只读，不影响任何记录与配置
